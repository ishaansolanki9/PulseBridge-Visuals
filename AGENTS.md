# Repository workflow

When the user asks for code changes in this repository, finish the verified change by committing the relevant source and documentation and pushing the active branch to `origin`, unless the user explicitly says not to push.

- Use a moderately descriptive commit subject and body that explain the user-visible behavior and important technical or reliability changes.
- Keep unrelated local files, personal media, generated transfer artifacts, credentials, and secrets out of commits.
- Report the pushed commit hash and verification performed in the final response.
